# NOTEBOOKLM
Esse repositório tem como objetivo auxiliar no desenvolvimento de estudos e armazenar projetos referente ao bootcamp promovido pela DIO+SantanderAcademy

## Tema 
Desenvolvimento de logotipo: conceitualização, design, registro e consolidação no mercado

## Objetivos:
* Adquirir conhecimento sobre as principais estratégias de criação de uma logomarca (marca, estruturação, paleta de cores, fonte e outros)
* Conhecer as regras para registro oficial, bem como o PaP
* Mapear os principais pontos de consolidação de uma marca no mercado através de cases de sucesso
 
## Motivação:
Investimento pessoal em pequenos negócios
